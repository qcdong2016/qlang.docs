# 21. 接口


同 Go：隐式满足，不写 implements。声明：`interface Name { ... };`。

### 21.0 Eq

预声明可比接口：

```
interface Eq {
    Equal(other any) bool
};
```

实现 `Eq` 的类型可用 `==` / `!=`，并可作 `Map` 的键。`a == b` 语义同 `a.Equal(b)`；`!=` 为其否定。

```
package demo

struct Point {
    x int
    y int
};

func Point.Equal(other any) bool {
    if typeof(other) != Point {
        return false
    }
    p := Point(other)
    return this.x == p.x && this.y == p.y
}

func f() {
    a := Point{x: 1, y: 2}
    b := Point{x: 1, y: 2}
    _ = a == b
    _ = a != b
}
```

### 21.1 定义与实现

```
package demo

interface Reader {
    Read(buf []u8) (int, error)
};

struct File : Ref {
    fd int
};

func File.Read(buf []u8) (int, error) {
    return 0, nil
}

func slurp(r Reader) (int, error) {
    buf := make([]u8, 64)
    return r.Read(buf)
}

func f() {
    f := File{fd: 1}
    slurp(f)
    var r Reader = f
    r.Read(nil)
}
```

空接口：

```
package demo

func f() {
    var a any = 1
    a = "x"
    a = Point{x: 1}
}
```

内嵌接口：

```
package demo

interface Reader {
    Read(buf []u8) (int, error)
};

interface Closer {
    Close() error
};

interface ReadCloser {
    Reader
    Closer
};
```

### 21.2 方法集

成员函数一律 `func T.Name`，`this` 为 `T`。接口由该类型满足：值结构体与 `struct T : Ref` 均为 `T`。

```
package demo

struct S { x int };
struct N : Ref { x int };

func S.A() {}
func N.C() {}

interface IA { A() };
interface IC { C() };

func f() {
    var s S
    var n N = N{}
    var a IA = s
    var c IC = n
    c = s            // 非法
}
```

### 21.3 类型断言

用 `typeof(expr) == T`。`typeof` 返回 `Type`，与类型名比较得 `bool`。取出具体值用转换 `T(expr)`。

```
package demo

struct Node : Ref { v int };

func Node.Read(buf []u8) (int, error) { return 0, nil }

interface Reader {
    Read(buf []u8) (int, error)
};

func f(r Reader) {
    if typeof(r) == Node {
        n := Node(r)
        n.v = 1
    }
}
```

```
package demo

func f(x any) {
    if typeof(x) == int {
        n := int(x)
        _ = n
    }
}
```

### 21.4 类型 switch

`switch typeof(x)`，`case` 写类型名。

```
package demo

struct Node : Ref { v int };

func f(x any) int {
    if x == nil {
        return 0
    }
    switch typeof(x) {
    case int:
        return int(x)
    case string:
        return len(string(x))
    case Node:
        return Node(x).v
    default:
        return -1
    }
}
```
