# 21. 接口


同 Go：隐式满足，不写 implements。声明：`interface Name { ... };`。

### 21.1 定义与实现

```
package demo

interface Reader {
    Read(buf []u8) (int, error)
};

struct File : Ref {
    fd int
};

func File.Read(buf []u8) (int, error) {
    return (0, nil)
}

func slurp(r Reader) (int, error) {
    buf := make([]u8, 64)
    return r.Read(buf)
}

func f() {
    f := File{fd: 1}
    slurp(f)
    var r Reader = f
    r.Read(nil)
}
```

空接口：

```
package demo

func f() {
    var a any = 1
    a = "x"
    a = Point{x: 1}
}
```

内嵌接口：

```
package demo

interface Reader {
    Read(buf []u8) (int, error)
};

interface Closer {
    Close() error
};

interface ReadCloser {
    Reader
    Closer
};
```

### 21.2 方法集

成员函数一律 `func T.Name`，`this` 为 `T`。接口由该类型满足：值结构体与 `struct T : Ref` 均为 `T`。

```
package demo

struct S { x int };
struct N : Ref { x int };

func S.A() {}
func N.C() {}

interface IA { A() };
interface IC { C() };

func f() {
    var s S
    var n N = N{}
    var a IA = s
    var c IC = n
    c = s            // 非法
}
```

### 21.3 类型断言

```
package demo

struct Node : Ref { v int };

func Node.Read(buf []u8) (int, error) { return (0, nil) }

interface Reader {
    Read(buf []u8) (int, error)
};

func f(r Reader) {
    n := r.(Node)
    n, ok := r.(Node)
    if ok {
        n.v = 1
    }
    t := r.(Node)
    n2 := t.0
    ok2 := t.1

}
```

单值断言失败会 panic。

### 21.4 类型 switch

```
package demo

func f(x any) int {
    switch v := x.(type) {
    case int:
        return v
    case string:
        return len(v)
    case Node:
        return v.v
    case nil:
        return 0
    default:
        return -1
    }
}
```
