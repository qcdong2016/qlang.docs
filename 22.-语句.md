# 22. 语句


### 22.1 块

```
package demo

func f() {
    x := 1
    {
        y := 2
        x = y
    }
}
```

### 22.2 if

```
package demo

func f(x int) int {
    if x > 0 {
        return 1
    }
    if x < 0 {
        return -1
    } else {
        return 0
    }
    if y := x - 1; y > 0 {
        return y
    }
    if err := g(); err != nil {
        return -1
    } else {
        return 0
    }
}
```

条件必须是 `bool`。没有括号。必须有 `{}`。

```
package demo

func f() {
    if 1 { }         // 非法
    if (true) { }    // 可以，但是多余
    if true return   // 非法：缺 {}
}
```

### 22.3 for

三种：C 三段、单条件、`range`。

```
package demo

func f() {
    for i := 0; i < 10; i++ {
        _ = i
    }
    for i := 0; i < 10; {
        i++
    }
    x := 0
    for x < 10 {
        x++
    }
    for {
        break
    }
}
```

```
package demo

func f() {
    a := []int{1, 2, 3}
    for i, v := range a {
        _ = i
        _ = v
    }
    for i := range a {
        _ = i
    }
    for _, v := range a {
        _ = v
    }
    for range a {
    }
    m := Map<string, int>{"a": 1}
    for k, v := range m {
        _ = k
        _ = v
    }
    s := "ab"
    for i, c := range s {
        _ = i
        _ = c
    }
}
```

`range` 数组/切片：`i, v` 中 `v` 是拷贝。`range` Ref 结构体不支持。

### 22.4 switch

```
package demo

func f(x int) int {
    switch x {
    case 1:
        return 1
    case 2, 3:
        return 2
    default:
        return 0
    }
}
```

无表达式等于 `switch true`：

```
package demo

func f(x int) int {
    switch {
    case x > 0:
        return 1
    case x < 0:
        return -1
    default:
        return 0
    }
}
```

带初始化：

```
package demo

func f(s string) int {
    switch n := len(s); n {
    case 0:
        return 0
    default:
        return n
    }
}
```

默认不贯穿。`fallthrough` 进入下一 case。

```
package demo

func f(x int) int {
    n := 0
    switch x {
    case 1:
        n = 1
        fallthrough
    case 2:
        n += 2
    }
    return n
}
```

### 22.5 break / continue / goto / 标签

```
package demo

func f() {
outer:
    for i := 0; i < 10; i++ {
        for j := 0; j < 10; j++ {
            if i == j {
                continue
            }
            if j == 5 {
                continue outer
            }
            if i == 8 {
                break outer
            }
        }
    }
done:
    goto done
}
```

```
package demo

func f(x int) {
    switch x {
    case 1:
        break
    default:
    }
}
```

### 22.6 return

```
package demo

func a() {
    return
}

func b() int {
    return 1
}

func c() (int, int) {
    return (1, 2)
}
```

### 22.7 defer

后进先出。函数返回前执行。参数当时求值。

```
package demo

struct File : Ref { fd int };

func File.Close() {}

func g() {
    f := File{fd: 1}
    defer f.Close()
    defer func() { }()
}
```
