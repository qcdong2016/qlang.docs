# 3. 关键字


```
package import func type struct interface
var if else for switch case default break continue
goto return defer range fallthrough any
true false nil
```

`this` 仅在 `func Class.Func` 体内有效，类型为 `T`。`error` `string` `int` `Ref` `Map` `Type`（元类型）`StructField` 等是预声明名，不是关键字。声明头 `type Name T` 里的 `type` 仍是关键字。`Ref` 只出现在 `struct Name : Ref`。`make` `len` `cap` `append` `sizeof` `panic` `recover` 是内建函数。
