# 8. 类型


### 8.0 声明

```
package demo

struct Point {
    x int
    y int
};

struct Node : Ref {
    next Node
    v    int
};

interface Reader {
    Read(buf []u8) (int, error)
};

struct Box<T Reader> {
    v T
};
```

`: Ref` 只能写在 `struct` 上。

```
package demo

interface Reader : Ref { }   // 非法
struct Point : Ref           // 非法：缺 {}
```

### 8.1 预声明

```
bool
char                    // u8
i8 i16 i32 i64
u8 u16 u32 u64
int uint                // 机器字宽
float                   // f64
f32 f64
string
error
any
Type                    // 类型值的类型
StructField              // 结构体成员引用的类型（struct field）
```

```
package demo

func f() {
    var a int = 1
    var b u8 = 255
    var c float = 1.5
    var d bool = true
    var e string = "hi"
    var f any = 1
}
```

### 8.2 命名类型

```
package demo

type Count int
type Name string

func f() {
    var n Count = 1
    var s Name = "a"
    var i int = int(n)
}
```

### 8.3 结构体、切片、数组、Map、函数

```
package demo

struct Point { x, y int };
struct Node : Ref { v int };

func f() {
    var a Point
    var c Node
    var d [4]int
    var e []int
    var g Map<string, int>
    var h func(int) int
    var w weak Node
}
```

Ref 与否由 `struct` 声明上的 `: Ref` 决定，类型名无 `&` 前缀。

### 8.4 多返回值

函数可声明多个返回值，同 Go。无元组类型。

```
package demo

func swap(a int, b int) (int, int) {
    return b, a
}

func open(path string) (int, error) {
    return 0, nil
}

func f() {
    a, b := swap(1, 2)
    fd, err := open("a")
    _ = a
    _ = b
    _ = fd
    _ = err
}
```
