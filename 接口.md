# 接口

隐式满足。声明 `interface Name { ... };`。`any` 是预声明空接口，同 Go。

```
interface Reader {
    Read(buf : []uint8) : (int, error)
};

struct File : Ref {
    fd : int
};

func File.Read(buf : []uint8) : (int, error) {
    return 0, nil
}

let r : Reader = File{fd: 1}
r.Read(nil)
```

```
let a : any = 1
a = "x"
```

```
interface ReadCloser {
    Reader
    Closer
};
```

值结构体与 `struct T : Ref` 均以 `T` 满足接口。

## 类型断言

```
if typeof(r) == File {
    f := File(r)
    _ = f
}
```

```
switch typeof(x) {
case int:
    return int(x)
case string:
    return len(string(x))
default:
    return -1
}
```

## error

```
interface error {
    Error() : string
};

fd, err := Open("a")
if err != nil {
    panic(err.Error())
}
```
